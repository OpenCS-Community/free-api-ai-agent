## Description
Challenge Description
Build a functional AI agent using Python and free-tier AI APIs. Your agent should answer questions, assist with coding, or perform useful tasks. Bonus points for multi-provider fallback, memory, and tool calling.

AI API Providers
Google Gemini — https://aistudio.google.com/
Groq — https://console.groq.com/
Cerebras — https://cloud.cerebras.ai/
OpenRouter — https://openrouter.ai/
Hugging Face — https://huggingface.co/
Cohere — https://dashboard.cohere.com/
Mistral AI — https://console.mistral.ai/
GitHub Models — https://github.com/marketplace/models/

Programming Language
Python

Recommended Libraries
openai, google-genai, groq, requests, python-dotenv, pydantic, fastapi, streamlit, pytest

Requirements
1. Integrate at least one AI API.
2. Implement useful agent features.
3. Protect API keys using environment variables.
4. Include a README.md, requirements.txt, and .env.example.
5. Publish your project on GitHub.

Challenge Goal
Build a working AI agent and share it with the OpenCS Community.
